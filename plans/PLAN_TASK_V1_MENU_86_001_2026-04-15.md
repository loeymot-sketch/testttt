## DESIGN DECISION — Avoiding frozen zone edits

The task's E7 proposes adding `decrementAndMaybe86()` directly inside `OrderService::confirm()` and `FrontendOrderService`. This would trigger a frozen zone gate.

**Alternative (adopted in this plan):** Use an **event listener** on `OrderCreated` to handle the decrement. Since `OrderCreated` is already dispatched after order commit (via outbox pattern from OUTBOX_001), a new listener `DecrementItemAvailabilityOnOrder` can:
1. Read order items from the newly created order.
2. Call `AvailabilityService::decrementAndMaybe86()` for each item.

This approach:
- **Avoids frozen zone edits entirely** — neither OrderService nor FrontendOrderService is modified.
- **Is symmetric by construction** — both services dispatch `OrderCreated`, so the listener handles both.
- **Leverages existing outbox infrastructure** — the decrement happens reliably after commit.

CREATE TABLE item_branch_availability (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    item_id BIGINT UNSIGNED NOT NULL,
    branch_id BIGINT UNSIGNED NOT NULL,
    is_available BOOLEAN NOT NULL DEFAULT 1,
    unavailable_reason VARCHAR(32) NULL,
    unavailable_since DATETIME NULL,
    max_daily_qty INT UNSIGNED NULL,
    daily_consumed_qty INT UNSIGNED NOT NULL DEFAULT 0,
    daily_reset_at DATE NOT NULL,
    created_at TIMESTAMP NULL,
    updated_at TIMESTAMP NULL,
    UNIQUE KEY uq_item_branch (item_id, branch_id),
    INDEX idx_branch_available (branch_id, is_available),
    FOREIGN KEY (item_id) REFERENCES items(id) ON DELETE CASCADE,
    FOREIGN KEY (branch_id) REFERENCES branches(id) ON DELETE CASCADE
);

### E3 — AvailabilityService

Create `app/Services/Menu/AvailabilityService.php`:

```php
final class AvailabilityService
{
    public function toggle(int $itemId, int $branchId, bool $available, ?string $reason = null): void
    {
        DB::transaction(function () use ($itemId, $branchId, $available, $reason) {
            $row = ItemBranchAvailability::firstOrCreate(
                ['item_id' => $itemId, 'branch_id' => $branchId],
                ['daily_reset_at' => today()]
            );
            $row->is_available = $available;
            $row->unavailable_reason = $available ? null : $reason;
            $row->unavailable_since = $available ? null : now();
            $row->save();
        });
        // After commit — dispatch event via existing infrastructure
        event(new ItemAvailabilityChanged(Item::find($itemId), 'availability', $branchId, $available, $reason));
    }

    public function decrementAndMaybe86(int $itemId, int $branchId, int $qty): void
    {
        $row = ItemBranchAvailability::where('item_id', $itemId)
            ->where('branch_id', $branchId)
            ->first();
        if (!$row || $row->max_daily_qty === null) return;
        // Reset if stale
        if ($row->daily_reset_at->lt(today())) {
            $row->daily_consumed_qty = 0;
            $row->daily_reset_at = today();
        }
        $row->daily_consumed_qty += $qty;
        $row->save();
        if ($row->daily_consumed_qty >= $row->max_daily_qty && $row->is_available) {
            $this->toggle($itemId, $branchId, false, UnavailableReason::OUT_OF_STOCK);
        }
    }

    public function isAvailable(int $itemId, int $branchId): bool
    {
        $row = ItemBranchAvailability::where('item_id', $itemId)
            ->where('branch_id', $branchId)
            ->first();
        return $row === null || $row->is_available;
    }

    public function getUnavailableItemIds(int $branchId): array
    {
        return ItemBranchAvailability::where('branch_id', $branchId)
            ->where('is_available', false)
            ->pluck('item_id')
            ->all();
    }
}
```

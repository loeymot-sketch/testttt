# PROD-LIVE-VALIDATION-D1-DESIGN-KIOSK

Implement an executable kiosk design smoke harness from the D1 Claude plan.

This first pass intentionally avoids product UI edits. It captures screenshots, console/runtime health, axe output, `data-testid` inventory and touch target data for accessible kiosk screens. Stateful screens that require order/cart fixtures are listed as follow-up before strict D1 PASS.

## 6. Risques résiduels (documentés, non bloquants merge)

Section « Incidental observations » du rapport verifier `VERIFY_P9_1_2026-04-18.md` :

1. **P1 — Payload `/frontend/order` carries client-computed prices** (ligne 334-383 de `kioskCart.js`). Le backend recalcule SSOT, donc pas de vulnérabilité de prix, mais ces champs `subtotal/discount/total/item_price/total_price` devraient être retirés du payload pour respecter strictement l'invariant « aucun prix client dans payload order ». À traiter en P9.5.1 (order pipeline hardening).
2. **P2 — `KioskPromoCarouselComponent`** UI promos server-driven (OK) mais pas d'indicateur « applicable au panier courant ». Non urgent.
3. **P2 — `KioskWizardComponent.vue:1158`** utilise Vue 2 `beforeDestroy` (compat layer Vue 3 OK). Candidat cleanup P9.7.
4. **P2 — per-line total recalculé client** dans `kioskCart.submitOrder`. Idem point 1, non-sec, cosmétique.

Les 4 points sont **incidentaux** : repérés pendant la revue mais hors scope P9.1. Ils sont tracés pour P9.5 (order hardening) / P9.7 (a11y+cleanup).

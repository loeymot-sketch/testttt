### Correctifs techniques effectués pendant l'exécution

1. **9.4.1 — `listTableIndexes` + DBAL** : l'introspection via `Doctrine\DBAL` plantait sur SQLite (`Class "Doctrine\\DBAL\\Driver\\AbstractSQLiteDriver" not found`). Remplacé par `try/catch` autour de `Schema::table()->unique(...)` — création d'index idempotente, aucun driver tiers requis.
2. **9.4.3 — PHPUnit `private function seed()`** : PHPUnit tentait d'interpréter le helper comme test method (fatal error "must be public"). Renommé en `seedLog()`.
3. **9.4.6 — `assertSame(5.00, ...)` sur cast JSON** : SQLite retourne `5` (int) pour `5.00` depuis un JSON. Remplacé par `assertEqualsWithDelta(5.00, (float) $value, 0.0001)`.
4. **9.4.7 — `orders.order_status`** : colonne réelle = `status`. `ZReportService::aggregate()` et le test aligné sur la colonne existante.

1. **P2 — `AvailabilityToggleRequest::authorize()` return `true` unconditionnel.** Gate effectif fourni par middleware `permission:items_edit`. Candidat défense-en-profondeur, non urgent.
2. **P2 — Super-admin (`branch_id=0`) scope = toutes branches.** Intentionnel, mais un gate explicite `role:SuperAdmin` préviendrait des toggles cross-branch accidentels. À intégrer dans le volet RBAC P9.4/P9.6.
3. **P3 — Plan texte : typo `allergen_item` vs pivot canonique `item_allergen`.** Code cohérent, plan à corriger.
4. **P3 — `ItemService::update` dispatche `ItemAvailabilityChanged` après `DB::transaction` sans helper `DB::afterCommit`.** Pattern pré-existant, à uniformiser avec les nouveaux `ItemCreated/Deleted` en refactor ultérieur (P9.5 order pipeline hardening probablement).
5. **P3 — `Tests\Feature\Database\AllergensSeederTest` (nouveau) chevauche `Tests\Feature\KioskPhase1\AllergensSeederTest`.** Consolidation cosmétique.
6. **P3 — Chemin 403 out-of-scope non couvert pour `AvailabilityController`.** Implémenté mais non testé. Ajout rapide P9.4/P9.6.

Ces 6 observations sont tracées dans ce rapport mais ne bloquent pas la fusion P9.2. Elles seront intégrées dans les vagues ultérieures selon priorité.

# Reports Directory

This unified directory holds the lifecycle of the Strict QA Loop used in this repository.

## Structure
- `antigravity/`: Contains test reports and audits generated by the Anti-Gravity agent. These files indicate what works and what fails.
- `planning/`: Contains execution plans generated by Cursor or Claude after reading the QA reports. These files describe *how* to fix the issues.
- `execution/`: Contains summaries generated by Claude or Kimi detailing what code was actually changed during the implementation phase.

## Workflow Rules
1. Test -> Report goes to `antigravity/`
2. Report -> Plan goes to `planning/`
3. Plan -> Code -> Execution Summary goes to `execution/`
4. Execution Summary -> Retest -> Back to Step 1.

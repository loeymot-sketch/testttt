This folder stores operational reports produced during the AI-assisted development cycle.

Structure:

reports/
  antigravity/   → QA reports generated by Anti-Gravity
  planning/      → task plans generated by Claude
  execution/     → summaries of implemented tasks

The workflow cycle is:

1. Anti-Gravity tests the application
2. A report is generated in reports/antigravity/
3. Cursor + Claude read the report
4. Claude produces a plan in reports/planning/
5. Tasks are executed (Claude or Kimi)
6. Implementation notes go to reports/execution/
7. Anti-Gravity retests

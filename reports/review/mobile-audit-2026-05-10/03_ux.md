### 1.2 Strengths (kiosk-aligned, keep these)

- Data model 1:1 with kiosk: `viandes`, `has_sauce`, `has_crudites`, `has_supplements`, `has_menu_addon` (`screens-main.jsx:241-247`).
- Crudités default ON + deselect-to-remove (`screens-main.jsx:263`) mirrors kiosk `KioskStepGarnituresComponent.vue:6-8`.
- Sauce 1-free / +0,50€/extra logic + "Sans Sauce" exclusive (`screens-main.jsx:275-283`) mirrors kiosk `KioskStepSauceComponent.vue:5-10` + `:188-192`.
- FIFO meat eviction at quota (`screens-main.jsx:271`) — graceful UX vs hard error.
- Single composition_summary builder (`screens-main.jsx:488-502`) is reusable for cart/recap.

## 3. Per-category active steps (state machine)

Note: steps are gated **per-item**, not per-category. The `viandes` count and `has_*` flags vary inside the same category (e.g. cat 2 Sandwichs has Le Suprême viandes:0 vs Le Méga viandes:2). Table shows the **dominant pattern** per category from `mobile/data/menu.js:147-254`; outliers noted in the rightmost column.

| Cat | Slug | viandes (range) | has_sauce | has_crud | has_supp | has_menu_addon | Active steps in order |
|---|---|---|---|---|---|---|---|
| 1 | nos-tacos | 1-4 | ✓ | ✓ | ✓ | ✓ | Viandes → Sauce → Crudités → Suppléments → Menu → [if full: FritesStyle → Drink] [if frites: FritesStyle] [if boisson: Drink] → Recap |
| 2 | nos-sandwichs | 0-2 (Suprême=0, Méga=2) | ✓ | ✓ | ✓ | ✓ | [if viandes>0: Viandes →] Sauce → Crudités → Suppléments → Menu → [cascade] → Recap |
| 3 | nos-burgers | 0 | ✓ | ✓ | ✓ | ✓ | Sauce → Crudités → Suppléments → Menu → [cascade] → Recap |
| 4 | nos-assiettes | 0 | ✓ | ✗ | ✓ | ✗ | Sauce → Suppléments → Recap (NOTE: cooking style for poulet — addressed in 5.W8) |
| 5 | ojja | 0 | ✓ | ✗ | ✓ | ✗ | Sauce → Suppléments → Recap |
| 6 | omelettes | 0 | ✓ | ✗ | ✓ | ✗ | Sauce → Suppléments → Recap |
| 7 | nos-salades | 0 | ✓ | ✗ | ✓ | ✗ | Sauce → Suppléments → Recap |

## 4. Navigation + transitions UX spec
### 4.1 Header (`ScreenHeader` — `mobile/shared.jsx:71-79`)

| Slot | Content | Behavior |
|---|---|---|
| `left` | `IconBtn` back arrow | First step → close modal/back to menu; subsequent → prev step |
| `center` | `n/N · {stepTitle}` (eyebrow + display) | Eyebrow `lc-eyebrow` (11px, 0.14em, uppercase) + step title `lc-display` 18px |
| `right` | `IconBtn` close ✕ | Always returns to menu (kill wizard, lose state — confirm modal if dirty) |

### 4.2 Progress dots (below header)
Reuse `Dots` (`shared.jsx:110-118`): `count=N`, `active=stepIndex`. Active 22px width `var(--ink)`, inactive 6px `rgba(0,0,0,0.2)`. Padding `8px 20px 14px`.

### 4.3 Sticky bottom CTA
Container `position: absolute; left: 16; right: 16; bottom: 24; z-index: 9` (mirrors `screens-main.jsx:477`). `lc-btn` h=60. States:
- Valid (1-7): `Suivant {+Δ€}  →` bg `--ink`, fg `#fff`, arrow yellow.
- Invalid (1-7): `Choisis {hint}` bg `--gray-2`, fg `--gray-4`, disabled.
- Recap: `🛍 Ajouter au panier · {total}€` bg `--orange`, fg `#fff`, `I.Bag` icon.

### 4.4 Slide transitions
Forward: enter `translateX(100%→0)`, leave `translateX(0→-30%)` opacity→0.6 over 240ms `ease-out`. Backward mirrors. Two stacked screens + `direction: 'fwd'|'back'` state. Disable on `prefers-reduced-motion`.

### 4.5 Composition live preview (P1)
Bottom-sheet handle (4px pull bar) above sticky CTA, peeking 28px. Tap → expands to 60% viewport with current selections + running total. Backdrop tap or pull-down closes. Reuses `ModalShell` (`screens-modals.jsx:6-16`). Cuts cognitive load on cat 1 (7+ steps).

### 4.6 Swipe gestures (P2)
Left-swipe=next, right-swipe=back. `touchstart`/`touchend` delta ≥60px and speed ≥0.3px/ms. Defer to Phase 5+.

## 5. Surprises / non-obvious decisions for AGENT-ADVERSARIAL
**5.1 Recap step vs floating "Voir mon panier" sheet** — Uber Eats/Deliveroo commit straight to cart with a sheet review; kiosk has no Recap (`KioskWizardComponent` valider→running total). **Proposal: keep Recap as a full step** — long flows (cat 1, 7+ steps) need a safety net; CTA running total covers mid-flow. Adversarial: argue Recap = friction, prefer cart sheet + edit-from-cart.

**5.2 Default crudités glyphs ✓/✕** — current `screens-main.jsx:403-407` uses green ✓ on, gray ✕+strike off. **Proposal: keep, add "AVEC/SANS" word labels** (mockup §2.3); ✓/✕ alone is ambiguous on touch. Adversarial: argue ✕ should DELETE the row instead of toggle.

**5.3 "Suivant" vs "Ajouter directement"** — on optional steps (Sauce/Crudités/Suppléments) we always force `Suivant`. **Proposal: linear step flow.** Skipping risks under-customization regret. Adversarial: argue a fast-track CTA on simple cats (assiettes/ojja) where only Sauce exists.

**5.4 Composition live preview pattern** — A. bottom-sheet pull-up (§4.5, proposed); B. side panel (no horizontal room on 390px); C. collapsed top bar (collides with eyebrow on long titles). **Proposal: A.** Adversarial: argue C with compact format (`4v·1s·2sup·+5,00€`).

**5.5 FritesStyle order** — kiosk runs FritesStyle BEFORE Boisson (`KioskStepMenuComponent.vue:96-147` → `:194-235`). **Proposal: same order (FritesStyle → Drink), price reveals progressively.** Adversarial: argue Drink first (more universal, less analysis paralysis).

**5.6 Per-step validation hint** — kiosk uses `role="status" aria-live="polite"` block at bottom of content (`KioskStepViandeComponent.vue:103-105`, `KioskStepSauceComponent.vue:65-67`). **Proposal: replicate, NOT in CTA label.** CTA stays minimal (`Suivant` or `Choisis 4 viandes`). Adversarial: argue DRY — pick one channel only.

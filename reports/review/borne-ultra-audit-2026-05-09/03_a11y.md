## Findings (5)

### [P0] [V1.0.1] Missing label-input association in `KioskLoyaltyComponent` register fields

Lines 87-130 : `<label class="kiosk-field-label">` lacks `for` attribute ; inputs lack `id`.
Labels visuellement présents mais **pas programmatiquement liés**. Screen readers ne peuvent pas
associer label text to input on focus. **WCAG 2.1 SC 1.3.1 (Info & Relationships) — fail
automated a11y audit**.

- `resources/js/components/frontend/kiosk/KioskLoyaltyComponent.vue:87-130`

**Fix** : ajouter `for="loyalty-email"` sur label + `id="loyalty-email"` sur input. ~10min.

### [P1] [V1] Div-based radio buttons (payment methods) — keyboard semantics partial

Lines 50-140 : trois `<div role="radio">` avec manual keydown handlers (`@keydown.enter.prevent`,
`@keydown.space.prevent`). WCAG 2.1 SC 2.1.1 framed V1.x pour kiosk (touch-primary), mais
`role="radio"` semantics requièrent arrow-key support (ARIA 1.2 radiogroup pattern).
Implementation actuelle Enter/Space only.

**Borderline** : touch kiosk doesn't *require* arrow keys par spec stricte ; ARIA radiogroup
contract expects them. Flag for V1.0.1 review si keyboard QA prévu.

- `resources/js/components/frontend/kiosk/KioskPaymentComponent.vue:50-140`

### [P1] [V1.x backlog — frozen-zone gate required] `KioskUpsellComponent` focus restoration

Lines 151-156 : composant lacks `_prevActive` / focus-restore machinery on unmount (unlike `KsModal`).
Si screen reader user navigates deeply dans upsell grid et auto-skip, focus retourne à document
root (default browser), pas à back button or cart.

**Low impact** : 30s timer, no user action normally triggers deep focus. V1.x polish.

⚠️ **Frozen-zone** : modification requires owner gate.

- `resources/js/components/frontend/kiosk/KioskUpsellComponent.vue:151-156`

### [P2] [V1] `KioskInactivityOverlayComponent` countdown — `aria-live` choice

Line 29 : countdown timer (`{{ secondsLeft }}`) announced via `aria-live="polite"`. Spec allows
polite (non-blocking), mais pour timer *destructif* (panier effacé), `assertive` plus
user-respectful.

**No WCAG breach** ; ARIA best-practice note only. Choix actuel défendable (intent : not
interrupt every second read).

- `resources/js/components/frontend/kiosk/KioskInactivityOverlayComponent.vue:29`

### [P2] [V1] `KioskOfflineConflictModalComponent` — semantics confirmées ✅

Lines 33-48 : deux `<button type="button">` proper HTML semantics. **No issue found.**
Marked P2 only for completeness (interactive controls properly marked). ✅

- `resources/js/components/frontend/kiosk/KioskOfflineConflictModalComponent.vue:33-48`

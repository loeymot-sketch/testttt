### 6.1 Contrast computations (tokens from `styles.css:5-19`)

Required: 4.5:1 body, 3:1 large/UI.

| "153 pts manquants" (`:912`) | --gray-3 | --cream #FAF7F2 | **3.1:1** | **FAIL body** |

#757066 (4.6:1) globally OR systematically substitute `var(--gray-4)` for body
text. The green button needs `--green-dark` ≥ #168842 to reach 4.5:1.

### 6.2 ARIA / semantic gaps

| Element | Required ARIA |
|---|---|
| Tabs container | `role="tablist"` + per-tab `role="tab"` + `aria-selected` + `aria-controls` |
| Tab content | `role="tabpanel"` + `aria-labelledby` |
| QR card | `role="img"` + `aria-label="Code QR fidélité, expire dans Xm Ys"` |
| TTL countdown | `role="timer"` + `aria-live="polite"` throttled |
| Progress bar | `role="progressbar"` + `aria-valuenow/max` + `aria-valuetext` |
| Reward list | `role="list"` + items `role="listitem"` |
| Locked button | `aria-disabled="true"` + `aria-describedby` reason |
| Redeem modal | `role="dialog"` + `aria-modal="true"` + focus trap + ESC close |
| Confetti | `aria-hidden="true"` |
| Hidden live region | `<div aria-live="polite" aria-atomic="true">` for balance changes |

### 6.3 QR refresh announcement strategy

When auto-regen every 5 min:
1. Update `<svg aria-label>` with new TTL text.
2. Trigger `aria-live="polite"`: "Code QR rafraîchi, valable 5 minutes."
3. **Throttle**: announce only on regen + at 60s remaining + at 10s. Never every second (VoiceOver spam).

### 6.4 Keyboard / focus

- `:focus-visible { outline: 2px solid var(--orange); outline-offset: 3px }` missing in `styles.css`.
- Modal focus not trapped (`ModalShell` uses background-click only).
- ESC key does not close modals.

### State B — Loading (first network fetch)
**Trigger**: balance fetch in flight.
**Today**: sync hardcoded — no loading state.

**Recommended**: 3 stacked skeletons (QR 200x200 shimmer + points 40px + 3
tab pills) using `@keyframes lc-pulse` (`styles.css:161`) at 1.6s ease infinite,
opacity 0.4→0.7.

### State C — Network error (balance fetch failed)
**Trigger**: 4xx/5xx or timeout on `GET /loyalty/balance`.
**Today**: silent crash or stale display of hardcoded 347.

**Recommended**: persistent banner above hero:
```
┌────────────────────────────────────┐
│ ⚠ Impossible de charger ton solde  │
│   Dernier solde connu : 347 pts    │
│   (mis à jour il y a 3 h).         │
│   [ Réessayer ]                    │
└────────────────────────────────────┘
```

- Show QR using cached HMAC if < 5 min old.
- Hide "UTILISER" actions if stale > 30 min (phantom-redeem risk on bad balance).

### Tracked but not "top 3"
- D — QR expired (>5min idle): greyed QR + "↻ Régénérer" prominent.
- E — Redeem 422 (insufficient pts): toast "Solde insuffisant" + refresh.

## Final summary

- **20 hardcoded values** — screen reads 0 data from `window.LC.loyalty`.
- **21 accidental gaps** vs kiosk (top-3: TTL countdown, RGPD opt-out, idempotent redeem).
- **Worst flow = Redeem** (5 taps, 3 decisions, no success state, no idempotency).
- **6 WCAG AA contrast failures** (all `--gray-3` body text).
- **3 critical states missing** (zero balance / loading / network error).

Top action: bind to `LC.loyalty`, fix label drift (BURGER at 500 vs 1000),
add TTL + idempotency, ship 3-step redeem wizard.

Est. effort items 1–7: **M+S+M+L+M+S+M ≈ 6–8 days** focused frontend
(backend hooks already documented in `data/loyalty.js`). Items 8 (Wallet) +
9 (Barcode) push to a second sprint.

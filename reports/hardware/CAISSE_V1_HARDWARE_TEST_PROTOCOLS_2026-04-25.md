# CAISSE V1 — Hardware Test Protocols

## 0. Règles d'exécution
- Chaque test doit être exécuté sur une branche de lab explicitement identifiée.
- Les numéros de série doivent être reportés dans la checklist avant démarrage.
- Les captures, tickets papier, logs et rapports Z doivent être archivés avec le numéro du test.
- Un test est PASS uniquement si le critère binaire est rempli et que la preuve est conservée.
- Owner technique par défaut : Ops Hardware + QA POS, sauf précision dans la ligne.

## 4. Adversarial findings

### F1 — P0 — `@group manual` annotation is non-functional in this repo
`phpunit.xml` defines **no** `<groups><exclude>manual</exclude></groups>` block. The four `@group manual` methods in `AllergenCoverageSentinelTest` therefore execute in CI and fail — matching the Wave Q-4 anti-pattern explicitly flagged in the W1.5 brief. The docblock author believed CI would skip them; CI does not.

Two valid heals (out of scope of this READ-ONLY audit):
- Add `<groups><exclude><group>manual</group></exclude></groups>` to `phpunit.xml`, OR
- Seed `LeCayenneAllergenSeeder` in test bootstrap so the sentinel actually passes.

### F2 — P1 — Duplicate sentinel file (PosCashEndpoint)

Both run. Likely a leftover from a move that did not delete the original. Confirm content parity and delete one.

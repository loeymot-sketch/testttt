# Brief images menu — pour le chargé de sourcing (PA)

**Dossier de livraison :** `public/images/menu/`  
**Formats :** PNG ou WebP haute qualité, **fond neutre** (blanc cassé ou gris très clair), **pas de logo ni marque** visible (pas de bouteilles Heinz, etc.).  
**Droits :** images **libres de droits** (ex. Pexels, Unsplash, Pixabay avec licence autorisant l’usage commercial) — garder la preuve (lien + auteur si demandé par la licence).

---

## Règles communes à toutes les photos

| Règle | Détail |
|--------|--------|
| Cadrage | **Carré ou quasi carré** (ex. 800×800 px minimum), sujet **centré**, même recul pour une même famille (sauces entre elles, suppléments entre eux, etc.). |
| Lumière | Lumière douce, pas d’ombres dures extrêmes. |
| Fond | Uni ou très léger dégradé neutre — **pas** de décor de cuisine chargé. |
| Cohérence | Dans une famille, **même type de prise de vue** (ex. toutes les sauces : même angle sur le bocal). |

---

## Sauces — charte obligatoire

**Toutes les sauces** doivent être montrées **dans le même type de récipient** : **bocal / pot / squeeze bottle en verre ou plastique neutre** (sans marque), **rempli** de la sauce concernée, **bouchon visible** si naturel.  
**Même angle** pour toutes (ex. ¾ face, légèrement de haut), **même hauteur** du pot dans le cadre, **même taille relative** dans l’image.

**Exception :** `sauce_sans` = **aucun bocal de sauce** : symbole « interdit » sobre ou **bocal vide / bouchon seul** sur fond neutre (cohérent avec le reste).

**Nommage :** fichiers **exactement** comme ci-dessous (extension **`.png`** à la livraison ; l’équipe technique adaptera la config si besoin).

## Checklist de livraison pour le PA

- [ ] Tous les fichiers **nommés exactement** comme dans ce document.  
- [ ] Sauces : **bocaux cohérents**, même angle et même style pour toute la série.  
- [ ] Aucune **marque** reconnaissable.  
- [ ] **Licence** documentée (lien source par image ou tableau fourni avec le lot).  
- [ ] Résolution **≥ 800 px** sur le plus petit côté pour les vignettes menu.
